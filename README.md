## عن التطبيق · About Qurani

**قرآني** تطبيق إسلامي مبني باستخدام **Flutter**، يجمع الأدوات اليومية التي تحتاجها في مكان واحد، بواجهة عربية واضحة وتصميم هادئ يسهل استخدامه.

**Qurani** is a Flutter-based, Arabic-first Islamic companion designed around everyday worship: quick access to prayer times, Quran reading, remembrance and Qibla direction.

## المميزات · Features

| القسم · Feature | التفاصيل · Details |
| :--- | :--- |
| 🕌 **مواقيت الصلاة · Prayer times** | مواعيد الصلاة حسب الموقع مع العد التنازلي للصلاة القادمة · Location-aware schedule and next-prayer countdown |
| 🔔 **تنبيهات الصلاة · Notifications** | إعدادات التنبيه للصلاة · Prayer reminder settings |
| 📖 **القرآن الكريم · Quran** | قراءة المصحف داخل التطبيق · In-app Mushaf reading |
| 📿 **التسبيح والأذكار · Tasbih & Adhkar** | عدّاد تسبيح وأذكار متنوعة · Tasbih counter and remembrance collections |
| 🕋 **القبلة · Qibla** | بوصلة لاتجاه القبلة · Qibla direction compass |
| 📚 **الأربعون النووية · Forty Nawawi** | الوصول إلى مجموعة الأربعين النووية · Access to the Forty Nawawi collection |
