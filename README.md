## قرآني · Qurani

**قرآني** تطبيق إسلامي مبني باستخدام **Flutter**، يجمع أهم الأدوات اليومية في تجربة عربية هادئة وواضحة: مواقيت الصلاة، القرآن الكريم، الأذكار، التسبيح واتجاه القبلة.

**Qurani** is an Arabic-first Islamic companion built with **Flutter**, bringing prayer times, Quran reading, adhkar, tasbih and Qibla guidance together in one focused mobile experience.
